# Book Selling Platform

Online bookstore for a mechanical engineering lecturer's books — ebooks and print, sold worldwide
with Paystack, Flutterwave and Stripe.

- `backend/` — NestJS + MongoDB API
- `frontend/` — Next.js + Tailwind storefront
- `docs/` — architecture, product rules, engineering rules, deployment, roadmap

All changes go through `feature/BS-<n>-<description>` branches and pull requests. `main` is protected.
